# @gcu/librarian — BM25F text search

A tiny in-process text search engine: inverted index, **BM25F** scoring with field boosts, **Damerau-Levenshtein** fuzzy expansion, synonym dictionary, prefix matching, snippet generation, and did-you-mean suggestions.

This demo indexes two public-domain corpora from Project Gutenberg:

- **Sherlock Holmes** — *The Adventures of Sherlock Holmes* (12 stories, long-form prose). Rewards entity searches like `Watson`, `Baker Street`, `Irene Adler`, and exercises proximity scoring.
- **Aesop's Fables** — Vernon Jones translation (284 micro-stories). Rewards thematic queries (`fox`, `wolf`, `pride`) and exercises the document-count statistics.

Pick a corpus, type a query, and watch the ranking shift. The fuzzy slider widens the tolerated edit distance — try `Wattson` or `Bakker`. Toggle synonyms to see expansion in action (`fox` → `foxes`, `pride` → `proud · vanity · vain`).

function docsFor(which) {
  const h = sherlock.map(s => ({ id: s.id, title: s.title, body: s.body, source: 'Holmes' }));
  const a = aesop.map(f => ({ id: f.id, title: f.title, body: f.body, source: 'Aesop' }));
  if (which === 'Holmes') return h;
  if (which === 'Aesop')  return a;
  return [...h, ...a];
}

## Try these

- **`Watson`** — heavyweight entity, hits all 12 Holmes stories
- **`Baker Street`** — proximity bonus rewards adjacent terms
- **`Irene Adler`** — appears in one story only; high precision
- **`Wattson`** — misspelt; needs fuzzy ≥ 1
- **`fox`** — Aesop bonanza; with synonyms also catches `foxes`
- **`pride`** — synonyms pick up `proud`, `vanity`, `vain`
- **`Moriarty`** — not in *Adventures*; did-you-mean fires the closest term

## How it works

`Librarian.index({ docs, fields, synonyms })` builds an inverted index keyed by token, with per-doc positions stored per field. Each entry in `docs` is `{ id, title, body, … }` — the field names match the `fields` config, which assigns a BM25F boost (`title: { boost: 4 }` means a hit in the title scores 4× a hit in the body).

`Librarian.search(index, query, opts)` tokenises the query, expands each token via synonyms + fuzzy + prefix matching, scores BM25F across fields, adds a proximity bonus for close-by hits within a doc, and returns ranked `{ doc, score, snippet, hits }` objects.

`Librarian.suggest(index, query)` finds the closest in-vocabulary terms when search hits zero — the did-you-mean fallback.

The whole engine is ~18 KB unminified, zero dependencies. See `ext/librarian/` for the source.
