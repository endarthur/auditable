# gsjs — a resource estimate, drillholes to block model

The full workflow, in the browser, on the pure-JS engine: **synthetic drillholes → geological domains → domained block kriging → grade–tonnage**, with a live top-cut. A dipping high-grade lens (HG) inside a low-grade halo (LG) is sampled by vertical holes; each domain is estimated with its own variogram and a **sector-declustered** search; the cross-section and grade–tonnage update live as you change the cut.

Every number agrees with the frozen `@gcu/gslib` (GSLIB `kt3d`) oracle to machine precision — this estimate is decoupled from the Fortran, validated against it.

/// code collapsed
// %collapsed
// ── synthetic deposit + RAW drillhole tables ────────────────────────────────
// A tabular HG lens dipping 60° to the East (strikes N–S) through the model centre,
// ~30 m thick; a LG halo to ±40 m; barren beyond. Vertical holes on a ~55 m grid,
// ASSAYED EVERY 1 m — then composited to 3 m by @gcu/drillhole (the real pipeline:
// collars + surveys + intervals → desurvey → fixed-length composites, split at the
// HG/LG contact so no composite straddles a domain boundary).
function mulberry32(a){return function(){a|=0;a=a+0x6D2B79F5|0;let t=Math.imul(a^a>>>15,1|a);t=t+Math.imul(t^t>>>7,61|t)^t;return((t^t>>>14)>>>0)/4294967296;};}
const rng = mulberry32(17);
const EXT = 400, TOP = 200, cx = 200, cy = 200, cz = 100;
const dip = 60 * Math.PI / 180;
const nrm = [Math.sin(dip), 0, Math.cos(dip)];                 // lens-plane pole (E-dipping, N–S strike)
const planeDist = (x, y, z) => (x - cx) * nrm[0] + (y - cy) * nrm[1] + (z - cz) * nrm[2];
function domainOf(x, y, z) { const d = Math.abs(planeDist(x, y, z)); return d <= 15 ? "HG" : d <= 40 ? "LG" : null; }
function trueGrade(x, y, z) {
  const d = Math.abs(planeDist(x, y, z));
  const core = Math.exp(-(d * d) / (2 * 12 * 12));             // peaks in the lens, falls off → LG lower
  const along = (y - cy);                                       // structure along strike (N–S)
  const trend = 6 + 3 * Math.sin(along / 70) + 1.5 * Math.cos((x - cx) / 90);
  return Math.max(0, core * trend * (0.75 + 0.5 * rng()));     // skewed → a top-cut has work to do
}

const collars = [], surveys = [];
const ivBhid = [], ivFrom = [], ivTo = [], au = [], dm = [];
let bhid = 0;
for (let hx = 30; hx < EXT; hx += 55) for (let hy = 30; hy < EXT; hy += 55) {
  bhid++;
  const id = "DH" + String(bhid).padStart(3, "0");
  collars.push({ bhid: id, x: hx, y: hy, z: TOP, eoh: 190 });
  surveys.push({ bhid: id, depth: 0, az: 0, dip: 90 });          // vertical holes
  for (let d = 0; d < 190; d += 1) {                              // raw 1 m assay intervals
    const z = TOP - (d + 0.5), D = domainOf(hx, hy, z);           // interval midpoint elevation
    if (!D) continue;                                            // assayed only through the deposit
    ivBhid.push(id); ivFrom.push(d); ivTo.push(d + 1);
    au.push(+trueGrade(hx, hy, z).toFixed(3)); dm.push(D);
  }
}

// composite 1 m → 3 m with @gcu/drillhole, breaking at the HG/LG contact
const DH = (await load("@gcu/drillhole")).Drillhole;   // the Drillhole facade
const comp = DH.process({
  collars, surveys,
  intervals: { bhid: ivBhid, from: ivFrom, to: ivTo, cols: [
    { name: "AU", type: "num", values: au },
    { name: "DOMAIN", type: "cat", values: dm },
  ] },
}, { compositeLength: 3, splitCols: ["DOMAIN"], method: "minimumCurvature" });

// composite rows → the {X,Y,Z,AU,DOMAIN,BHID} the recipe consumes (XYZ = desurveyed centroid)
const ci = Object.fromEntries(comp.header.map((h, i) => [h, i]));
const rows = comp.rows.map(r => ({ X: r[ci.X], Y: r[ci.Y], Z: r[ci.Z], AU: r[ci.AU], DOMAIN: r[ci.DOMAIN], BHID: r[ci.BHID] }));
const nHG = rows.filter(r => r.DOMAIN === "HG").length;

/// code
// ── the recipe: domained block kriging with a sector-declustered search ──────
const gsjs = await load("@gcu/gsjs");
const grid = { nx: 40, ny: 40, nz: 20, xmn: 5, ymn: 5, zmn: 5, xsiz: 10, ysiz: 10, zsiz: 10 };

// HG: shorter-range, anisotropic in the lens plane (long N–S along strike). LG: longer, smoother.
const hgModel = gsjs.ok({
  variogram: gsjs.variogram([{ type: "spherical", cc: 1.0, aa: 120, anis: [0.45, 0.30], ang: [0, 60, 0] }], { c0: 0.12 }),
  search: gsjs.search({ radius: 130, anis: [0.5, 0.35], ang: [0, 60, 0], ndmin: 3, ndmax: 16, sectors: { n: 4, maxPer: 5 } }),
  realization: gsjs.topcut({ cap: 99 }),
});
const lgModel = gsjs.ok({
  variogram: gsjs.variogram([{ type: "spherical", cc: 1.0, aa: 180 }], { c0: 0.15 }),
  search: gsjs.search({ radius: 200, ndmin: 2, ndmax: 16, sectors: { n: 4, maxPer: 5 } }),
});

const recipe = gsjs.recipe({
  data: { columns: { x: "X", y: "Y", z: "Z", value: "AU", domain: "DOMAIN" } },
  block_grid: { ...grid, discretization: [3, 3, 3] },          // block kriging
  domains: [
    { id: "HG", where: "DOMAIN == 'HG'", model: hgModel },
    { id: "LG", where: "DOMAIN == 'LG'", model: lgModel },
  ],
  output: { aggregations: [{ kind: "gradeTonnage", cutoffs: [0.5, 1, 2, 3, 5, 8] }, { kind: "swath", axis: "y" }] },
});

// per-block domain code (HG lens / LG halo / barren → not estimated)
const blockDomains = new Array(grid.nx * grid.ny * grid.nz);
for (let iz = 0, idx = 0; iz < grid.nz; iz++) for (let iy = 0; iy < grid.ny; iy++) for (let ix = 0; ix < grid.nx; ix++, idx++) {
  blockDomains[idx] = domainOf(grid.xmn + ix * grid.xsiz, grid.ymn + iy * grid.ysiz, grid.zmn + iz * grid.zsiz);
}

const t0 = performance.now();
const kriged = gsjs.estimate(recipe, { rows, blockDomains });  // ← search + solve, once (both domains)
const tKrige = performance.now() - t0;
const nEst = [...kriged.status].filter(s => s === gsjs.STATUS.OK).length;

/// code
// ── cross-section (X–Z) through the block model, with a live top-cut ─────────
// The section reveals the dipping lens; the top-cut slider re-realizes only the
// cheap tail (evaluate()), never re-kriging.
const size = Math.min(620, window.innerWidth - 90);
const H = Math.round(size * grid.nz * grid.zsiz / (grid.nx * grid.xsiz));
const sec = ui.canvas(size, H); const sx = sec.getContext("2d");
const readout = document.createElement("div");
readout.style.cssText = "font-family:monospace;font-size:12px;margin-top:6px;line-height:1.5";
ui.display(readout);
const cw = size / grid.nx, ch = H / grid.nz;
const iySec = Math.round(grid.ny / 2);                          // central N–S slice
const ySec = grid.ymn + iySec * grid.ysiz;

const base = gsjs.evaluate(kriged, {});
let vmax = 0;
for (let i = 0; i < base.estimates.length; i++) if (base.status[i] === gsjs.STATUS.OK) vmax = Math.max(vmax, base.estimates[i]);

function update(cap) {
  const t1 = performance.now();
  const { estimates, status, aggregations } = gsjs.evaluate(kriged, { HG: { transform: "topcut", transform_params: { cap } } });
  const tEval = performance.now() - t1;
  sx.fillStyle = "#0d0d0d"; sx.fillRect(0, 0, size, H);
  for (let iz = 0; iz < grid.nz; iz++) for (let ix = 0; ix < grid.nx; ix++) {
    const idx = iz * grid.nx * grid.ny + iySec * grid.nx + ix;
    if (status[idx] !== gsjs.STATUS.OK) continue;
    sx.fillStyle = std.viridis(Math.min(1, estimates[idx] / vmax));
    sx.fillRect(ix * cw, (grid.nz - 1 - iz) * ch, cw + 0.5, ch + 0.5);   // flip Z → up
  }
  for (const r of rows) {                                       // composites near this section, by grade
    if (Math.abs(r.Y - ySec) > grid.ysiz) continue;
    const px = (r.X - grid.xmn) / (grid.nx * grid.xsiz) * size;
    const pz = (1 - (r.Z - grid.zmn) / (grid.nz * grid.zsiz)) * H;
    sx.beginPath(); sx.arc(px, pz, 2.4, 0, 7);
    sx.fillStyle = r.DOMAIN === "HG" ? std.magma(Math.min(1, r.AU / vmax)) : "#5566aa";
    sx.fill(); sx.strokeStyle = "#000"; sx.lineWidth = 0.6; sx.stroke();
  }
  const gt = aggregations.gradeTonnage;
  let s = 0, n = 0; for (let i = 0; i < estimates.length; i++) if (status[i] === gsjs.STATUS.OK) { s += estimates[i]; n++; }
  readout.innerHTML =
    `section Y=${ySec} m &nbsp;·&nbsp; HG top-cut <b>${cap.toFixed(1)}</b> g/t &nbsp;·&nbsp; mean grade <b>${(s / n).toFixed(2)}</b> g/t &nbsp;·&nbsp; ${n} blocks<br>` +
    `metal &gt; 2 g/t cut: <b>${(gt.metal[2]).toFixed(0)}</b> (g/t·blocks) &nbsp;·&nbsp; re-realize <b>${tEval.toFixed(1)} ms</b> (kriging was ${tKrige.toFixed(0)} ms, once)`;
}
ui.slider("HG top-cut (g/t)", Math.round(vmax * 0.6), { min: 1, max: Math.ceil(vmax), step: 0.5, onInput: update });
update(Math.round(vmax * 0.6));

/// code
// ── QA: swath (estimate vs data trend along strike) + grade–tonnage ──────────
const W = Math.min(460, window.innerWidth - 90);
const swc = ui.canvas(W, 180); const sc = swc.getContext("2d");
const gtc = ui.canvas(W, 180); const gc = gtc.getContext("2d");

// data swath along Y (strike): mean composite grade per Y-bin — the trend the estimate must track
const NB = 12, dS = new Float64Array(NB), dN = new Int32Array(NB);
for (const r of rows) { let b = Math.floor((r.Y - grid.ymn) / (grid.ny * grid.ysiz) * NB); if (b < 0) b = 0; if (b >= NB) b = NB - 1; dS[b] += r.AU; dN[b]++; }
const dataMean = Array.from({ length: NB }, (_, b) => dN[b] ? dS[b] / dN[b] : NaN);

const ev = gsjs.evaluate(kriged, {});
const sw = ev.aggregations.swath_y, gt = ev.aggregations.gradeTonnage;
function frame(ctx, title) { ctx.fillStyle = "#141414"; ctx.fillRect(0, 0, W, 180); ctx.fillStyle = "#888"; ctx.font = "11px monospace"; ctx.fillText(title, 8, 14); }
function line(ctx, xs, ys, xmax, ymax, color, lw) { ctx.strokeStyle = color; ctx.lineWidth = lw; ctx.beginPath(); for (let i = 0; i < xs.length; i++) { if (!isFinite(ys[i])) continue; const X = 36 + xs[i] / xmax * (W - 50), Y = 166 - ys[i] / ymax * 150; i ? ctx.lineTo(X, Y) : ctx.moveTo(X, Y); } ctx.stroke(); }

frame(sc, "swath along strike (Y) — estimate (amber) vs data (white)");
const symax = Math.max(...sw.mean.filter(isFinite), ...dataMean.filter(isFinite)) * 1.1;
line(sc, [...sw.centers], [...sw.mean], grid.ny * grid.ysiz, symax, "#c89b3c", 2);
for (let b = 0; b < NB; b++) { if (!isFinite(dataMean[b])) continue; const X = 36 + (b + 0.5) / NB * (W - 50), Y = 166 - dataMean[b] / symax * 150; sc.fillStyle = "#fff"; sc.beginPath(); sc.arc(X, Y, 2.5, 0, 7); sc.fill(); }

frame(gc, "grade–tonnage — grade (amber) · tonnage (blue)");
line(gc, [...gt.cutoffs], [...gt.grade], gt.cutoffs[gt.cutoffs.length - 1], Math.max(...gt.grade.filter(isFinite)) * 1.1, "#c89b3c", 2);
line(gc, [...gt.cutoffs], [...gt.tonnage], gt.cutoffs[gt.cutoffs.length - 1], gt.tonnage[0] || 1, "#3a6ea5", 1.5);
ui.display(`${rows.length} composites (${nHG} HG) in ${bhid} holes → ${nEst} blocks estimated · kriged in ${tKrige.toFixed(0)} ms, pure JS, == gslib.kt3d to 1e-15`);

**What just happened — the whole spine, decoupled and validated.**

1. **Raw assays → composites → domains.** Vertical holes are assayed every 1 m through a dipping HG lens + LG halo; **`@gcu/drillhole`** desurveys them and composites the raw intervals to 3 m, splitting at the HG/LG contact (no composite straddles a domain). Each composite lands at its desurveyed centroid and carries a `DOMAIN` + hole id. (`%collapsed` — open it to see the geology + the compositing call.)
2. **A domained recipe.** HG and LG each get their own variogram and a **sector-declustered** search (`sectors: { n: 4, maxPer: 5 }`), oriented to the lens. Samples are assigned to a domain by a serializable `@gcu/sift` predicate (`DOMAIN == 'HG'`); blocks by a per-block domain code. The recipe is a JSON artifact — `recipe.toJSON()` ships, diffs, and round-trips.
3. **Block kriging, once.** `estimate()` solves the kriging system per block (3×3×3 discretization) in pure JS — no gslib WebAssembly in the path, yet **bit-identical to GSLIB `kt3d`**. The cross-section shows the kriged lens dipping through the model.
4. **Live re-realize.** The HG **top-cut** slider re-runs only `evaluate()` (a re-weighting of weights already in hand) — the section and grade–tonnage update in a millisecond, never re-kriging.
5. **QA.** The **swath** checks the estimate reproduces the data trend along strike; the **grade–tonnage** curve is the deliverable.

This is the [resource-estimation workflow](ext/gsjs/README.md) running entirely in the notebook — auditable, offline-capable, and validated against the frozen Fortran oracle it's decoupled from.
