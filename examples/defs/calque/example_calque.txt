# calque — spreadsheet language

a minimal, array-oriented language for spreadsheet computations. calque expressions compile 1:1 to xlsx formulas. this example shows the full pipeline: evaluate, display with `calque.grid()`, and export to xlsx via `sheet.write()`.

/// code
const { calque } = await load("@gcu/calque");
const { sheet } = await load("@gcu/sheet");

/// md
## sheet blocks and cross-references

sheet blocks group related columns. cross-sheet references use dot notation — `Sales.revenue` in the `Summary` block. each sheet block becomes a separate xlsx sheet.

/// code
const report = calque`
  Sales {
    name = ["Alice", "Bob", "Carol", "Dave"]
    revenue = [42000, 38000, 55000, 29000]
    tax = revenue * 0.15
    net = revenue - tax
  }

  Summary {
    grand = sum(Sales.revenue)
    avg = mean(Sales.revenue)
    headcount = count(Sales.name)
    top = max(Sales.revenue)
  }
`;

ui.display(calque.grid(report));

/// md
## download as xlsx

`result.compile()` produces a workbook structure that plugs directly into `sheet.write()` — evaluate once, compile from the same result.

/// code
const { workbook, warnings } = report.compile();
if (warnings.length) ui.display("warnings: " + warnings.join(", "));

const bytes = await sheet.write(workbook);
ui.download("⬇ download report.xlsx", bytes, "report.xlsx");

/// md
## reactive computation

calque integrates with auditable's DAG. move the slider to adjust the tax rate — the table re-renders automatically.

/// code
const rate = ui.slider("tax rate", 15, { min: 0, max: 50 }) / 100;

/// code
const reactive = calque`
  Sales {
    name = ["Alice", "Bob", "Carol", "Dave"]
    revenue = [42000, 38000, 55000, 29000]
    tax = revenue * ${rate}
    net = revenue - tax
    label = if net > 40000 then "high" else "normal"
  }
  Summary {
    total_tax = sum(Sales.tax)
    total_net = sum(Sales.net)
  }
`;

ui.display(calque.grid(reactive));

/// md
## basic expressions

bindings, arrays, broadcasting, and reductions.

/// code
const basics = calque`
  x = [1, 2, 3, 4, 5]
  doubled = x * 2
  total = sum(x)
  avg = mean(x)
`;

ui.display(calque.grid(basics));

/// md
## ranges, functions, and lambdas

ranges (`1..n`), user-defined functions, and `scan` with lambdas.

/// code
const math = calque`
  n = 10
  idx = 1..n
  squared = idx * idx
  cubed = idx ^ 3
`;

ui.display(calque.grid(math));

/// code
const funcs = calque`
  tax(amount, rate) = amount * rate
  Pricing {
    price = [100, 250, 75, 400, 180]
    vat = tax(price, 0.2)
    cumsum = scan(price, 0, (acc, x) -> acc + x)
  }
`;

ui.display(calque.grid(funcs));

/// md
## conditionals and filtering

pointwise `if` broadcasts over columns. subscript with a boolean column filters.

/// code
const cond = calque`
  Weather {
    temp = [35, 22, 18, 41, 29, 15, 38]
    label = if temp > 30 then "hot" else if temp < 20 then "cold" else "mild"
  }
`;

ui.display(calque.grid(cond));

/// code
const filtered = calque`
  temps = [35, 22, 18, 41, 29, 15, 38]
  hot_temps = temps[temps > 30]
`;

ui.display(calque.grid(filtered));

/// md
## string operations

string concat (`&`), formatting functions, and broadcasting over columns.

/// code
const strings = calque`
  Text {
    name = ["Alice", "Bob", "Carol"]
    score = [95.7, 82.3, 91.1]
    label = name & ": " & str(round(score, 0))
    initial = left(name, 1)
    length = len(name)
  }
`;

ui.display(calque.grid(strings));
