# notebook filesystem

`notebook.fs` is an embedded filesystem stored inside the notebook HTML. files are compressed and base64-encoded — they survive saves, packed saves, and reloads. open the **files** panel from the ellipsis menu to browse and manage embedded files.

use cases:
- bundle input data (CSV, JSON) so notebooks are self-contained
- store computed results that persist across sessions
- embed JS/WASM libraries that don't work through `install()`
- snapshot canvas renders as PNG

## canvas snapshots

save a canvas rendering as a PNG in the filesystem — it persists across saves and reloads.

/// code
const size = Math.min(400, window.innerWidth - 80);
const c = ui.canvas(size, size);
const ctx = c.getContext("2d");

// dark background
ctx.fillStyle = "#1a1a1a";
ctx.fillRect(0, 0, size, size);

// plot cities
const [lonMin, lonMax] = std.extent(cities, d => d.lon);
const [latMin, latMax] = std.extent(cities, d => d.lat);
const pad = 40;

for (const city of cities) {
  const x = pad + (city.lon - lonMin) / (lonMax - lonMin) * (size - 2 * pad);
  const y = pad + (latMax - city.lat) / (latMax - latMin) * (size - 2 * pad);
  const r = Math.sqrt(city.pop / 1e6) * 1.5;

  ctx.beginPath();
  ctx.arc(x, y, r, 0, Math.PI * 2);
  ctx.fillStyle = "rgba(200, 155, 60, 0.7)";
  ctx.fill();
  ctx.strokeStyle = "#c89b3c";
  ctx.stroke();

  ctx.fillStyle = "#999";
  ctx.font = "10px monospace";
  ctx.fillText(city.city, x + r + 4, y + 3);
}

ctx.fillStyle = "#555";
ctx.font = "10px monospace";
ctx.fillText("population (circle area)", pad, size - 12);

// save the canvas as PNG in the filesystem
await notebook.fs.write("plots/cities.png", c);
ui.display(`saved canvas as plots/cities.png (${notebook.fs.stat("plots/cities.png").size} bytes)`);

## load JS from the filesystem

embed a helper module in the notebook and import it with `load("fs:...")`. the module lives inside the HTML file — no network needed.

/// code
// write a JS module into the filesystem
await notebook.fs.write("lib/geo.js", `
export function haversine(lat1, lon1, lat2, lon2) {
  const R = 6371;
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = Math.sin(dLat/2)**2 +
    Math.cos(lat1 * Math.PI/180) * Math.cos(lat2 * Math.PI/180) *
    Math.sin(dLon/2)**2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
}

export function bearing(lat1, lon1, lat2, lon2) {
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const y = Math.sin(dLon) * Math.cos(lat2 * Math.PI/180);
  const x = Math.cos(lat1 * Math.PI/180) * Math.sin(lat2 * Math.PI/180) -
    Math.sin(lat1 * Math.PI/180) * Math.cos(lat2 * Math.PI/180) * Math.cos(dLon);
  return (Math.atan2(y, x) * 180 / Math.PI + 360) % 360;
}
`);

// import from the filesystem — works offline after save
const { haversine, bearing } = await load("fs:lib/geo.js");

// compute distances from Tokyo to all other cities
const tokyo = cities[0];
const distances = cities.slice(1).map(c => ({
  from: tokyo.city,
  to: c.city,
  km: Math.round(haversine(tokyo.lat, tokyo.lon, c.lat, c.lon)),
  bearing: bearing(tokyo.lat, tokyo.lon, c.lat, c.lon).toFixed(1) + "\u00b0",
}));

ui.table(distances);

## zip archive

`std.zipArchive()` and `std.unzipArchive()` create and extract zip files using browser-native compression. combine with `notebook.fs.export()` for folder downloads.

/// code
// create a zip from embedded files
const entries = new Map();
for (const f of notebook.fs.list("data/")) {
  entries.set(f.path.replace("data/", ""), await notebook.fs.read(f.path, "binary"));
}

const zipBytes = await std.zipArchive(entries);
ui.display(`zip: ${zipBytes.length} bytes, ${entries.size} entries`);

// unzip it back
const extracted = await std.unzipArchive(zipBytes);
for (const [name, data] of extracted) {
  ui.display(`  ${name}: ${data.length} bytes`);
}
