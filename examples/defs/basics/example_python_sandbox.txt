# Python sandbox

A base notebook with the GCU replacement libraries for the Python scientific stack pre-loaded. **Drop a `.ipynb` file** onto the page (or use **File → Open .ipynb…**) and its imports get auto-rewritten via `@gcu/ipynb`:

| Jupyter | Auditable | adder import | status |
|---|---|---|---|
| `numpy` / `np` | natra | `import natra as np` | ✓ loaded |
| `pandas` / `pd` | sadpan | `import sadpan as pd` | ✓ loaded |
| `matplotlib.pyplot` / `plt` | plt | `import plt` | ✓ loaded |
| `sklearn` | learn | `import learn` | ✓ loaded |
| `scipy` | scitra | `import scitra` | no adder.js adapter yet (see ROADMAP) |

The libs without ✓ status get rewritten on import but fail at runtime. That's intentional — the failing import is the honest signal for which adapter to wire next.

This notebook ships in **manual execution mode** (cells only run on Ctrl+Enter or Run All) so you don't get a Jupyter notebook chain-firing on every slider drag.

## smoke test — verify each library loaded

/// adder
import natra as np
import sadpan as pd

# natra: a few primitives
x = np.linspace(0, 10, 5)
print("natra x:", x)
# Scalar shape works too — numpy parity: zeros(3) ≡ zeros([3]).
print("natra zeros:", np.zeros(3))

# sadpan: small DataFrame
df = pd.DataFrame({
    "city": ["São Paulo", "Belo Horizonte", "Rio"],
    "pop_m": [12.3, 2.5, 6.7],
})
df

/// adder
import plt

# plt: line plot of a sine wave (natra has np.sin).
# fig.show() returns the rendered canvas — `fig` alone shows the JSON state.
# In Jupyter matplotlib, `fig` would auto-render via plt's inline backend;
# here that's an explicit .show() call.
fig, ax = plt.subplots()
xs = np.linspace(0, 6.28, 100)
ys = np.sin(xs)
ax.plot(xs.tolist(), ys.tolist())
fig.show()

/// adder
# learn: fit a decision tree on a tiny dataset and predict
from learn.tree import DecisionTreeClassifier

X = [[0, 0], [0, 1], [1, 0], [1, 1]]
y = [0, 1, 1, 0]

clf = DecisionTreeClassifier(random_state=0)
clf.fit(X, y)
print("XOR predictions:", clf.predict([[0, 0], [1, 1], [0, 1]]))
