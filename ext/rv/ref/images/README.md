# Test Images

Pre-built Linux kernel + Busybox images for testing the RV32IMA emulator.

These images are **not** part of the rv emulator source and are licensed
separately from the rest of the project.

## Image.bin

NOMMU Linux 6.8-rc1 + Busybox for RV32IMA, single flat binary.
