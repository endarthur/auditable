@gcu/term — interactive demo

Three live terminals exercising the v0.1 surface — basic ANSI output, REPL-style line discipline, and a streaming log viewer. Each example has a dispose button that tears the terminal down (kills its DOM, drops its listeners, calls dispose() on Input + Terminal + DomRenderer). After dispose, further interaction is inert.

1. ANSI palette + cursor + alt-screen

Demonstrates SGR colors (16-color, 256-color, truecolor), bold / italic / underline, the cursor blink, and an alt-screen toggle. Click the buttons to see how they translate to byte streams the terminal consumes.

ready

2. tiny REPL (echo + line buffer)

Type into the terminal — it edits a local line buffer, prints characters as you type, and on Enter "evaluates" by sending the line back as a colored response. Backspace works. Demonstrates the byte-stream contract and shows where a real REPL host would call adder.evalLine() or similar.

ready — focus the terminal and type

3. log viewer (output-only stream)

Streams synthetic log lines at 5 Hz. Cursor hidden. Mouse-wheel scrolls the viewport into scrollback (default 1000 rows); Shift+PgUp / Shift+PgDn scroll by page; clicking the terminal and typing snaps back to live. Pause to inspect; resume to follow.
