# @gcu/dd60

The **DD-60 "DADA Diskman"** surface for Auditable Works — a retro reader skin
(a de-branded Sony Data Discman homage) over the same `book.json` content the
Book reader uses. An easter-egg surface: Library-installable, not in the default
profiles.

Contributes a **surface** (`works.js` → `surface.html`, kind `dd60`). Same lib
deps as `@gcu/book` (`@gcu/docview` + `@gcu/katex` + `@gcu/librarian` +
`@gcu/reader-core`) via `gcu.requires`.

See EXTENSION_SPEC §3.8.
