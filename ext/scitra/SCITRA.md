# scitra — scientific computing primitives

`ext/scitra/` — scipy-subset for the browser, backed by natra/atra. JS orchestration + atra kernels for hot paths. all operations work inside natra scopes.

## Modules

- **optimize** — Levenberg-Marquardt (variogram fitting), Nelder-Mead, BFGS, Brent/bisect/Newton root finding. three-tier model dispatch: JS callback → atra function ref (call_indirect) → atra inlined (zero-call-overhead specialized kernel)
- **stats** — distributions (normal, lognormal, chi2, t) with pdf/cdf/ppf/rvs/fit. weighted descriptives (mean, variance, percentile, ecdf, histogram). normal score transform with tie-breaking strategies (midpoint/jitter/random), plotting positions (Hazen/Blom/Tukey/Weibull), tail extrapolation (linear/power/hyperbolic), BDL handling. multivariate: Gaussian PCA, stepwise conditional, PPMT
- **spatial** — KD-tree with anisotropic search, octant/sector constraints, drillhole-aware max-per-group. distance matrices (cdist/pdist with anisotropy). block discretization. Voronoi/Delaunay (stretch)
- **interpolate** — interp1d (linear/nearest/cubic), cubic spline, lookup tables
- **integrate** — adaptive quadrature, Gauss-Legendre, trapz/cumtrapz
- **ndimage** — convolution, Gaussian filter, mathematical morphology (binary + greyscale erosion/dilation/opening/closing), distance transforms, connected component labeling. optional WebGPU path for large 3D grids
- **fft** — radix-2 Cooley-Tukey (1D/2D), real-input FFT, power spectrum
